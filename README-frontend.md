# AI Launch Kit — Frontend

React + Vite frontend for the AI Launch Kit. Connects to the backend API running on `http://localhost:8000`.

## Requirements
- Node.js 18+
- npm

## Run locally
```bash
cd ~/Downloads/FINAL/ai-launch
npm install
npm run dev
```
The app will start on the Vite dev server (usually http://localhost:5173).

> Note: start the backend first (see the backend repo README) so API calls work.
